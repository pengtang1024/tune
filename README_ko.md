# Tune - 당신의 개인 멜로디 상자

Tune은 로컬 음악 컬렉션을 정리하고 재생하기 위해 깨끗하고 직관적인 인터페이스를 제공하도록 설계된 음악 플레이어 애플리케이션입니다.

## 기능

- **로컬 음악 라이브러리 관리**: 로컬 음악 파일을 쉽게 정리
- **사용자 정의 재생목록**: 장르, 분위기, 상황별로 재생목록 생성
- **부드러운 재생 경험**: 고품질 오디오 재생을 즐기기
- **이퀄라이저**: 사용자 정의 가능한 사운드 설정으로 오디오 미세 조정
- **미니멀리스트 인터페이스**: 음악 경험에 집중한 깨끗한 디자인

## 설치

1. 컴퓨터에 Flutter가 설치되어 있는지 확인
2. 이 저장소를 클론
3. 종속성을 설치하려면 `flutter pub get` 실행
4. 장치를 연결하거나 에뮬레이터 시작
5. 애플리케이션을 시작하려면 `flutter run` 실행

## 프로젝트 설명

Tune: 모든 멜로디가 돌아갈 곳을 찾게 하다 바쁜 일상 속에서, 마음속에 조용히 정착하는 멜로디가 언제든지 있습니다. 아침에 깨워주는 경쾌한 리듬일 수도 있고, 심야에 동반해주는 부드러운 민요일 수도 있으며, 여행 도중 우연히 만난 기쁜 싱글일 수도 있습니다.

Tune은 단순한 음악 플레이어가 아니라 당신의 개인적인 "멜로디 보관함"입니다. 여기서 로컬 음악 라이브러리를 쉽게 정리하고, 스타일, 분위기, 상황별로 재생목록을 사용자 정의하여 각 곡이 가장 적합한 위치에서 당신을 기다리도록 할 수 있습니다. 매끄러운 재생 경험과 섬세한 음향 조절을 통해 헤드폰의 모든 음표가 선명하고 풍부해지며, 마치 현장에 있는 것처럼 느껴집니다. 심플하면서도 세련된 인터페이스 디자인은 음악에 대한 순수한 사랑을 숨기고, 불필요한 산만함 없이 당신과 음악만의 고요한 시간을 제공합니다.

수년간 간직한 클래식한 명곡이든, 최근 발견한 니치한 걸작이든, Tune은 모두를 적절히 보관하여 매번 열 때마다 아름다운 청각적 재회가 되도록 합니다.

Tune과 함께 음악을 본질로 되돌리고, 모든 순간을 멜로디와 함께 보내세요.
