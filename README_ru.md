# Tune

[中文](README.md) · [English](README_en.md) · [日本語](README_ja.md) · [한국어](README_ko.md) · [Русский](README_ru.md)

Tune — компактный локальный и онлайн-музыкальный плеер на Flutter. Слева постоянно находится плеер, справа переключаются библиотека, очередь и настройки.

## Возможности

- Сканирование, поиск и сохранение локальных музыкальных папок
- Онлайн-источники: Openverse, Jamendo, Internet Archive, ccMixter, превью iTunes, подкасты по RSS, Audius, Wikimedia Commons, интернет-радио, а также собственный NeteaseCloudMusicApi, Navidrome/Subsonic или Jellyfin
- Добавление, удаление, перетаскивание и очистка очереди
- Воспроизведение/пауза, предыдущий/следующий трек, перемотка, громкость, режимы повтора
- Фильтр библиотеки по источнику; для удалённых треков показываются источник и обложка
- Светлая/тёмная/системная тема; сохранение путей сканирования и настроек источников
- Языки интерфейса: 简体中文, 繁體中文, 中文（通用）, English — названия источников, даты и числа следуют выбранному языку
- Окно 900×600 по умолчанию, минимум 760×520

## Стек

- Flutter, Riverpod, go_router
- just_audio; в Linux — just_audio_media_kit + системный libmpv
- Dio, shared_preferences, file_picker
- flutter_localizations / gen-l10n

## Структура

```text
lib/
├── app/                  # вход, маршрутизация, тема, оболочка
├── features/             # player / library / queue / settings / sources
├── data/services/        # аудио, сканирование, адаптеры источников, хранение
├── domain/models/        # Song, настройки источника, результаты сканирования
├── shared/               # общие UI и утилиты
└── l10n/                 # локализация
```

Модель источников описана в [需求/音源设计.md](需求/音源设计.md) (на китайском).

## Ограничения

- Основная платформа текущей версии — Linux desktop.
- Для удалённого воспроизведения нужна сеть; настольная версия сначала кэширует треки локально, веб-версия только транслирует поток.
- URL удалённых потоков могут истекать; Netease, Subsonic, подкасты по RSS и Jellyfin обновляют адрес отдельного трека, остальным источникам нужен повторный скан.
- Интернет-радио — это живой поток: он не кэшируется и не показывает полосу прогресса.
- Старые мобильные уведомления, тексты песен, эквалайзер, история и аккаунт исключены из основного сценария.
