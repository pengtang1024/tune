Tune - это больше, чем просто музыкальный плеер; это ваша личная "коробка для хранения мелодий". Здесь вы можете легко организовать свою локальную музыкальную библиотеку, настроить плейлисты по стилю, настроению или сцене, гарантируя, что каждая песня будет ждать вас в наиболее подходящем месте. Благодаря плавному воспроизведению в сочетании с изысканной настройкой звука, каждая нота в ваших наушниках становится четкой и насыщенной, как будто вы находитесь на месте события. Дизайн интерфейса, простой, но изысканный, скрывает чистую любовь к музыке, без лишних отвлекающих факторов - только вы и ваша музыка в одиночестве.

Будь то классические хиты, хранимые годами, или недавно обнаруженные нишевые шедевры, Tune может аккуратно разместить их все, делая каждое открытие прекрасным слуховым воссоединением.

С Tune музыка возвращается к своей сути, и каждый момент сопровождается мелодиями.

## 🎵 Основные возможности

🎵 **Управление локальной музыкальной библиотекой** - Легко организуйте свои локальные музыкальные файлы с помощью чистого и интуитивно понятного интерфейса

📋 **Пользовательские плейлисты** - Создавайте плейлисты по жанрам, настроению или сцене для идеального прослушивания

🔊 **Высококачественное воспроизведение аудио** - Интегрирован с just_audio для высококачественного воспроизведения аудио с поддержкой нескольких форматов (MP3, FLAC, WAV и др.)

🎚️ **Эквалайзер и управление звуком** - Тонкая настройка звука с настраиваемыми параметрами звука и управлением громкостью

🎨 **Несколько тем** - Выберите одну из 5 красивых предустановленных тем (Trendy Electro, Minimal Gray, Nature Forest, Cyber Neon, Warm Healing) с поддержкой светлого/темного режима

🌍 **Многоязычная поддержка** - Полная поддержка 5 языков (английский, китайский, японский, корейский, русский) с легким переключением

📱 **Кроссплатформенность** - Красиво спроектирован для мобильных устройств, настольных компьютеров и веба с адаптивными макетами

⏯️ **Фоновое воспроизведение** - Продолжайте слушать при использовании других приложений с элементами управления уведомлениями

## 🏗️ Техническая архитектура

Этот проект использует многоуровневую архитектуру шаблона Clean Architecture + BLoC для обеспечения кроссплатформенной согласованности и удобства сопровождения.

### Слои архитектуры

```
lib/
├── config/                 # Файлы конфигурации
│   └── theme/              # Конфигурация темы
├── core/                   # Основной слой
│   ├── di/                 # Внедрение зависимостей
│   ├── routes/             # Управление маршрутами
│   ├── services/           # Основные сервисы
│   └── utils/              # Вспомогательные классы
├── data/                   # Слой данных
│   ├── datasources/        # Источники данных
│   ├── models/             # Модели данных
│   └── repositories/       # Реализации репозиториев
├── domain/                 # Слой домена
│   ├── entities/           # Сущности
│   ├── repositories/       # Интерфейсы репозиториев
│   └── usecases/           # Варианты использования
└── presentation/           # Слой представления
    ├── bloc/               # Управление состоянием
    ├── pages/              # Страницы
    ├── widgets/            # Общие компоненты
    └── components/         # Бизнес-компоненты
```

### Основные модули

- **Модуль ядра воспроизведения аудио** - Реализует воспроизведение, паузу, пропуск и управление прогрессом с помощью just_audio
- **Модуль музыкальной библиотеки** - Пользовательская реализация для получения локальной музыки с поддержкой онлайн-стриминга
- **Модуль плейлиста** - Использует Hive для хранения плейлистов
- **Пользовательский модуль** - Поддержка стороннего входа с использованием shared_preferences для пользовательских сессий
- **Модуль UI/UX** - Адаптивный дизайн с настраиваемыми темами и темным режимом

## 📦 Основной технологический стек

- **Управление состоянием**: [flutter_bloc](https://pub.dev/packages/flutter_bloc)
- **Управление маршрутами**: [auto_route](https://pub.dev/packages/auto_route)
- **Воспроизведение аудио**: [just_audio](https://pub.dev/packages/just_audio)
- **Получение локальной музыки**: Пользовательская реализация
- **Управление разрешениями**: [permission_handler](https://pub.dev/packages/permission_handler)
- **Внедрение зависимостей**: [get_it](https://pub.dev/packages/get_it)
- **Интернационализация**: [flutter_localizations](https://pub.dev/packages/flutter_localizations)

## 🎯 Адаптация платформы

- **Мобильные устройства**: Следует рекомендациям по дизайну платформы с фоновым воспроизведением, элементами управления на экране блокировки и уведомлениями
