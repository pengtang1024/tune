## 🎵 Tuneについて

忙しい日常の中で、心にそっと住み着く旋律があります — 朝にあなたを起こす明るいリズム、深夜に付き添ってくれる優しい民谣、旅の途中で偶然出会うサプライズのシングル曲かもしれません。

Tuneは音楽プレーヤー以上のもので、あなたの個人的な「旋律収納箱」です。ここで、ローカル音楽ライブラリを簡単に整理し、スタイル、気分、シーン別にプレイリストをカスタマイズできます。各楽曲が最も適した場所で待っていてくれます。スムーズな再生体験と繊細な音響調整により、ヘッドフォンの各音符がクリアで豊かに響き、まるでライブ会場にいるかのように感じられます。シンプルでありながら洗練されたインターフェースデザインには、音楽への純粋な愛が込められており、余計な邪魔がなく、あなたと音楽だけの寛ぎの時間があります。

何年も大切にしているクラシックな楽曲でも、新しく発見したマイナーな名作でも、Tuneが丁寧に保管してくれ、毎回の再生が美しい聴覚の再会になります。

Tuneで、音楽を本来の姿に戻し、すべての時間に旋律をともなってください。

## 🌟 特徴

- 🎧 **高品質オーディオ再生** - MP3、FLAC、WAVなど複数のオーディオフォーマットをサポート
- 📚 **ローカル音楽管理** - ローカル音楽ライブラリを自動スキャン・整理、メタデータ解析に対応
- 🎨 **マルチテーマサポート** - 8種類の美しいテーマ（トレディ・エレクトロ、ミニマルグレー、ナチュラルフォレスト、サイバーネオン、ウォームヒーリングなど）、ダーク/ライトモードの自動切替
- 🌍 **多言語サポート** - 中国語、英語、日本語、韓国語、ロシア語をサポート
- 📱 **クロスプラットフォーム互換性** - Android、iOS、Windows、macOS、Linux、Webを全面サポート
- ⚡ **スムーズな体験** - バックグラウンド再生、通知コントロール、クイック検索
- 🎛️ **パーソナライゼーション** - フォント、テーマ、言語など豊富なカスタマイズオプション
- 🎯 **スマートレコメンド** - 再生履歴に基づくパーソナライズされた音楽レコメンド
- 📥 **オフラインキャッシュ** - オンライン音楽のキャッシュをサポートし、いつでも音楽を楽しめます
- 📋 **プレイリスト** - カスタムプレイリストの作成と管理をサポート
- 🔄 **複数再生モード** - リストループ、シングルループ、シャッフル再生
- ⏩ **再生コントロール** - 再生進捗のドラッグ、音量調整、再生速度調整(0.5x-2.0x)をサポート
- 🎵 **歌詞同期** - LRCフォーマットの歌詞をリアルタイム表示に対応
- 🔍 **スマート検索** - 楽曲名、アーティスト、アルバムでの検索をサポート

## 🎨 テーマプレビュー

Tuneは選べる複数の美しいテーマを提供します：

1. **トレンディ・エレクトロ** - 紫を基調としたモダンな電子スタイル
2. **ミニマル・グレー** - クリーンなグレートーンデザイン
3. **ナチュラル・フォレスト** - 新鮮なグリーンのナチュラルスタイル
4. **サイバー・ネオン** - 未来感のあるネオンカラー
5. **ウォーム・ヒーリング** - 温かみのあるオレンジのヒーリングスタイル
6. **ウォーム・オレンジ・グラデーション** - グラデーションオレンジの暖色スタイル
7. **モノクローム** - 統一カラーのミニマルデザイン
8. **ビビッドレッド** - 情熱的な赤のテーマ

すべてのテーマは「ライトモードでは明るく透明感があり、ダークモードでは繊細で洗練された」というデザイン理念に従い、低彩度のカラーマッチングで高級感を演出します。

## 🛠 技術アーキテクチャ

TuneはClean Architecture + BLoCパターンを採用し、コードの保守性と拡張性を確保しています：

```
lib/
├── app/                    # アプリケーションコア設定
│   ├── router/             # ルーティング管理
│   └── theme/              # テーマシステム
├── core/                   # コア層
│   ├── bloc/               # グローバル状態管理
│   ├── config/             # アプリケーション設定
│   ├── error/              # エラーハンドリング
│   ├── network/            # ネットワーク関連
│   ├── services/           # コアサービス
│   ├── storage/            # データストレージ
│   ├── utils/              # ユーティリティクラス
│   └── widgets/            # コアコンポーネント
├── features/               # 機能モジュール
│   ├── audio/              # オーディオ再生機能
│   ├── home/               # ホームモジュール
│   ├── library/            # 音楽ライブラリモジュール
│   ├── player/             # プレーヤーモジュール
│   ├── profile/            # プロフィールモジュール
│   ├── search/             # 検索モジュール
│   └── settings/           # 設定モジュール
├── l10n/                   # 国際化リソース
└── di/                     # 依存性注入
```

## 🚀 クイックスタート

### 環境要件

- Flutter SDK 3.8.1 以上
- Dart SDK 3.8.1 以上
- サポート対象IDE (Android Studio / VS Code)

### 依存関係のインストール

```bash
flutter pub get
```

### アプリケーションの実行

```bash
# 開発モードで実行
flutter run

# 特定プラットフォーム向けにビルド
flutter build apk      # Android
flutter build ios      # iOS
flutter build web      # Web
flutter build windows  # Windows
flutter build macos    # macOS
flutter build linux    # Linux
```

## 🔧 主要依存関係

- **オーディオ再生**: [just_audio](https://pub.dev/packages/just_audio)
- **状態管理**: [flutter_bloc](https://pub.dev/packages/flutter_bloc)
- **ルーティング**: [auto_route](https://pub.dev/packages/auto_route)
- **ローカルストレージ**: [hive](https://pub.dev/packages/hive), [shared_preferences](https://pub.dev/packages/shared_preferences)
- **ネットワークリクエスト**: [dio](https://pub.dev/packages/dio)
- **依存性注入**: [get_it](https://pub.dev/packages/get_it)
- **国際化**: [flutter_localizations](https://flutter.dev/docs/development/accessibility-and-localization/internationalization)
