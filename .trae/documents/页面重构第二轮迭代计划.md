# 页面重构第二轮迭代计划

## 1. 现状分析

完成了第一轮重构，现在需要继续优化：

- **设置页面**：GeneralTab、MusicLibraryTab、AboutTab 仍在使用旧的 Card 组件，未统一风格
- **播放器内容**：PlayerContent 较为简单，可进一步美化
- **歌曲列表**：需要查看并优化歌曲卡片显示
- **缺少新组件**：设置项需要使用新的 SettingsItem 组件

## 2. 本轮迭代目标

### 美观度
- ✨ 统一设置页面所有组件风格
- 🎵 优化播放器内容区域
- 📋 美化歌曲列表展示

### 易用性
- 🎯 改进设置项交互反馈
- 🔍 优化歌曲信息展示
- ⚡ 提升整体操作体验

## 3. 具体任务

### 任务 1：重构 GeneralTab（通用设置）
- 使用新的 AppDesignSystem 样式
- 用 SettingsItem 替换旧的 Card 组件
- 移除 ThemePreviewCard 简化设计
- 优化开关、下拉框、滑块样式

### 任务 2：重构 MusicLibraryTab（音乐库设置）
- 使用 ModernCard 和 SettingsItem
- 优化自定义路径列表显示
- 简化说明内容布局
- 提升整体视觉效果

### 任务 3：重构 AboutTab（关于页面）
- 使用新的设计系统
- 优化应用 Logo 和信息展示
- 美化功能特点区域
- 改进链接和联系方式样式

### 任务 4：优化 PlayerContent（播放器内容）
- 使用 AppDesignSystem 文本样式
- 优化专辑封面展示
- 改进歌曲信息布局
- 添加更精致的视觉效果

### 任务 5：检查并优化歌曲卡片
- 查看 SongGridWidget 和相关组件
- 统一卡片设计风格
- 优化列表项显示

## 4. 迭代执行顺序

1. 重构 GeneralTab
2. 重构 MusicLibraryTab
3. 重构 AboutTab
4. 优化 PlayerContent
5. 检查并优化歌曲列表
