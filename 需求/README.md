## 📋 项目概述

**Tune** 是一款专注于提供简洁直观界面的跨平台音乐播放器应用，旨在帮助用户管理和播放本地音乐库。本项目采用 Flutter 框架开发，遵循 Clean Architecture 架构模式，为用户提供高质量的音频播放体验。

### 🎯 核心目标

- 提供跨平台一致的音乐播放体验
- 支持本地音乐库的高效管理
- 实现个性化设置（主题、音效调节等）
- 优化移动端后台播放和通知栏控制

## 📐 开发原则

1. **Clean Architecture 分层架构**
   - 严格遵循表现层、领域层、数据层、核心层的分离
   - 确保业务逻辑与 UI 解耦

2. **BLoC 状态管理**
   - 使用 flutter_bloc 进行状态管理
   - 区分全局状态和局部状态

3. **模块化设计**
   - 实现模块化设计，确保低耦合
   - 支持按需加载功能模块

4. **跨平台一致性**
   - 保证各平台体验一致性
   - 适配平台特性

5. **国际化支持**
   - 支持多语言切换
   - 遵循国际化最佳实践

6. **性能优化**
   - 注重性能优化和异常处理
   - 保证流畅的用户体验

## 🎯 主要功能模块

### 音乐播放模块
- 支持多种音频格式（MP3、FLAC、WAV等）
- 播放控制（播放/暂停/停止/上一首/下一首）
- 音量控制和播放进度控制
- 播放模式（列表循环、单曲循环、随机播放）
- 播放速度调节（0.5x~2.0x）

### 音乐库模块
- 本地音乐扫描与管理
- 元数据解析（标题、艺术家、专辑、封面等）
- 分类管理（按艺术家、专辑、流派等）
- 在线音乐资源支持

### 播放列表模块
- 创建、编辑、删除播放列表
- 本地存储和云端同步
- 支持拖拽排序和批量操作

### 用户模块
- 第三方登录（微信、QQ、支付宝等）
- 游客模式支持
- 数据同步和隐私控制

### UI/UX 模块
- 响应式设计适配多种屏幕尺寸
- 多套预设主题和自定义主题支持
- 深色/浅色模式自动切换
- 歌词同步显示
