## 📋 项目概述

**Tune** 是一款紧凑的桌面音乐播放器，统一管理本地音乐目录与在线音源，聚焦播放、队列、扫描和基础设置。本项目采用 Flutter 开发，按 feature 划分表现层与控制器，数据层与 UI 解耦。

### 🎯 核心目标

- 在 900×600（最小 760×520）窗口内提供高信息密度的播放体验
- 高效扫描、搜索、筛选本地与在线歌曲
- 通过适配器接入开放曲库和自建 API 音源
- 保持主题、语言、扫描目录和音源配置可持久化

| 类别 | 技术/工具 |

## 📱 平台适配要求

### 桌面端（Linux 优先）
- ✅ 900×600 默认窗口与 760×520 最小窗口
- ✅ 窗口管理、紧凑双栏布局
- ✅ 本地文件与在线音源统一播放

### 移动端 / Web
- 移动端与 Web 保留 Flutter 工程入口，但不是当前 v1 的主验收平台。
- 通知栏控制、锁屏控制等旧能力已退出当前主链路。
- Linux 桌面的后台播放（系统媒体控制 + 系统托盘）与默认播放器见 [桌面集成方案](桌面集成方案.md)。

## 📐 开发原则

1. **Clean Architecture 分层架构**
   - 严格遵循表现层、领域层、数据层、核心层的分离
   - 确保业务逻辑与 UI 解耦

2. **Riverpod 状态管理**
   - 使用 Riverpod 区分全局状态与局部状态
   - 播放状态唯一来源为 `PlaybackController`

3. **模块化设计**
   - 实现模块化设计，确保低耦合
   - 支持按需加载功能模块

4. **跨平台一致性**
   - 保证各平台体验一致性
   - 适配平台特性

5. **国际化支持**
   - 支持多语言切换
   - 遵循国际化最佳实践

6. **性能优化**
   - 注重性能优化和异常处理
   - 保证流畅的用户体验

## 🎯 主要功能模块

### 音乐播放模块
- 本地文件与远程流媒体统一播放
- 播放/暂停、上一首/下一首、进度拖拽、音量
- 列表循环、单曲循环、随机播放
- 播放队列增删、拖拽重排与清空

### 音乐库模块
- 本地目录扫描与远程音源扫描
- 搜索与按来源筛选
- 远程歌曲封面、来源标识
- 扫描失败按音源隔离，保留缓存

### 音源模块
- 内置本地目录、Openverse、Jamendo、Internet Archive、Netease API 适配器
- 音源开关、配置校验、自动扫描间隔
- 启动自动扫描，失败保留缓存

### UI/UX 模块
- 紧凑双栏布局：左播放器 + 右内容区
- 音乐库 / 队列页签，设置作为右栏路由
- 浅色 / 深色 / 系统主题
- 多语言选择；当前 v1 主要使用中文文案

## 🧪 测试策略

- 单元测试覆盖核心业务逻辑
- 集成测试验证模块间交互
- 跨平台测试确保功能一致性
- 异常测试验证错误处理机制

## 📈 扩展性考虑

- 新音源通过 `MusicSourceAdapter` 接入，无需修改播放器和音乐库 UI
- 音源配置字段由适配器声明，设置页动态渲染
- 播放入口与音乐库解耦，便于后续加入离线缓存或下载
- 主题与语言保持独立配置
