请基于以下详细需求，完善音乐应用的核心功能实现，解决未开发功能缺口，优化 UI/UX 体验，确保跨平台兼容性，并通过全面测试修复潜在 bug，最终实现无异常稳定运行的生产级应用。
一、核心功能模块完善需求（优先级：高）
1. 音频播放核心功能（基于 just_audio）
   基础播放控制
   核心操作：实现「播放 / 暂停」「上一首 / 下一首」「停止」功能，通过 BLoC 管理播放状态（Playing/Paused/Stopped），UI 实时同步状态变化；
   进度控制：实现播放进度拖拽（滑块组件），实时显示当前播放时间（如1:30/3:45），进度条支持点击跳转播放位置；
   音量调节：支持系统音量集成 + 应用内音量滑块，静音状态同步显示（图标变化）。
   播放模式与顺序
   播放模式：实现 3 种模式切换 —— 列表循环、单曲循环、随机播放，通过图标状态（循环箭头 / 随机图标高亮）直观展示当前模式；
   顺序控制：随机播放时记录已播放歌曲列表，避免短时间内重复播放；单曲循环时锁定当前歌曲，进度结束后自动重新播放。
   播放速度与音质
   速度调节：支持 0.5x~2.0x 播放速度调节（步进 0.1x），调节后实时生效，UI 显示当前速度值（如1.2x）；
   音质适配：根据音频文件格式（MP3/FLAC 等）自动适配播放参数，支持用户手动切换「标准音质」「高音质」（影响缓存大小）。
   异常处理（关键）
   播放错误：处理文件损坏、格式不支持、路径无效等错误，弹窗提示 “播放失败，请检查文件” 并自动跳转下一首；
   网络异常：在线播放时断网，自动切换至已缓存部分播放，弹窗提示 “网络中断，已切换至离线模式”；
   资源释放：退出播放页面 / 应用后台时，暂停播放并释放音频资源，避免内存泄漏；
   状态恢复：应用重启后，自动恢复上次播放状态（歌曲、进度、模式）。
2. 歌词功能实现（LRC 解析 + 实时同步）
   歌词解析：支持 LRC 格式歌词解析，提取时间戳（如[01:30.50]）与歌词文本，处理多行歌词、翻译歌词（如[01:30.50][t]Translation）；
   实时同步：通过音频播放进度流（positionStream）匹配对应时间戳歌词，当前歌词高亮显示，支持上下滚动查看前后歌词；
   UI 展示：歌词页支持全屏 / 半屏切换，夜间模式下歌词文本与背景对比度≥4.5:1，避免视觉疲劳；
   异常处理：无歌词文件时显示 “暂无歌词”，歌词格式错误时提示 “歌词解析失败”。
3. 本地音乐扫描与管理
   扫描功能：实现「全盘扫描」「指定文件夹扫描」，支持手动触发扫描 / 自动定期扫描（默认每周），扫描时显示进度条（“扫描中：35/120 首”）；
   元数据解析：提取歌曲标题、艺术家、专辑、封面、时长等信息，解析失败时用 “未知歌曲”“未知艺术家” 兜底；
   分类管理：扫描完成后按「全部歌曲」「艺术家」「专辑」「流派」自动分类，支持按 “最近添加”“播放次数”“字母序” 排序。
   二、UI/UX 与个性化功能完善（优先级：中）
1. 多语言切换功能
   语言支持：内置中文（简体）、英文，支持动态切换，切换后无需重启应用，UI 实时刷新；
   语言包管理：语言包以 JSON 格式存储（zh.json/en.json），支持通过远程下载新增语言包（如粤语、日语），实现热更新；
   适配细节：所有文本（按钮、提示、歌词）均通过Localizations获取，避免硬编码；日期、时间格式随语言自动适配（如中文 “2024 年 10 月” vs 英文 “Oct 2024”）。
2. 主题切换与自定义
   预设主题：提供至少 3 套预设主题（极简灰调、活力轻电、暗夜星空），支持浅色 / 深色模式自动跟随系统切换；
   自定义主题：允许用户自定义主色调（通过色盘选择）、圆角半径（4px/8px/12px）、卡片阴影强度，自定义后实时预览效果；
   跨平台适配：移动端主题强调触控反馈（按钮高亮），桌面端强化阴影层次，Web 端优化文本对比度（符合 WCAG 标准）。
3. 响应式布局优化（跨平台）
   移动端：全屏沉浸式播放页，底部固定播放控制栏（迷你播放器），滑动切换页面时保留播放栏；
   桌面端：支持窗口化布局（最小宽度 600px），左侧固定导航栏，右侧内容区，播放控制栏置于底部或侧边；
   Web 端：响应式适配（≤768px 时切换移动端布局），优化触摸 / 鼠标交互（ hover 效果仅在桌面端显示）。
   三、社交与互动功能实现（优先级：中）
1. 核心互动功能
   收藏 / 取消收藏：支持对歌曲 / 专辑 / 播放列表进行收藏，收藏状态通过 “心型图标”（空心 / 实心）展示，收藏数据本地存储 + 登录后云端同步；
   点赞 / 评论：在线歌曲支持点赞（显示点赞数）、评论（输入框 + 评论列表），评论支持表情、文字，本地缓存最近 10 条评论；
   分享功能：支持分享歌曲 / 播放列表至微信、QQ、微博等平台，分享内容含歌曲名、封面、播放链接（Web 端生成临时链接，移动端直接跳转 APP）。
2. 搜索与历史记录
   搜索功能：实现全局搜索框，支持按 “歌曲名、艺术家、专辑” 搜索，输入时实时联想推荐（显示匹配结果），支持搜索历史快速选择；
   历史记录：自动记录搜索关键词、播放历史（保留最近 100 条），支持手动清除单条 / 全部历史，隐私模式下可关闭历史记录。
3. 播放列表与收藏夹
   播放列表管理：支持创建（输入名称）、编辑（重命名 / 删除）、排序（拖拽调整顺序），播放列表内支持批量添加 / 删除歌曲；
   收藏夹：默认生成 “我喜欢的歌曲” 收藏夹，收藏歌曲自动加入，支持手动移除，收藏夹支持离线缓存。
   四、下载与缓存管理
   下载功能：在线歌曲支持手动下载（“下载按钮”），设置下载路径（默认/Music/Downloads），显示下载进度（百分比 + 进度条），支持暂停 / 取消下载；
   缓存管理：自动缓存在线播放歌曲（默认缓存 7 天），提供 “清理缓存” 功能（按大小 / 时间筛选），显示缓存占用空间（如 “2.5GB”）；
   下载设置：支持设置 “仅 Wi-Fi 下载”“下载音质选择”“缓存上限”（如 5GB），超出上限时自动删除最早缓存。
   五、跨平台适配细节（优先级：高）
1. 移动端（Android/iOS）
   后台播放：支持应用退到后台后继续播放，通知栏显示迷你播放器（含封面、标题、播放 / 暂停 / 切歌按钮）；
   锁屏控制：Android 锁屏界面显示歌曲信息 + 控制按钮，iOS 支持控制中心集成；
   权限适配：首次使用时申请 “存储权限”（本地音乐）、“网络权限”（在线功能），无权限时引导至设置页开启。
2. 桌面端（Windows/macOS/Linux）
   系统集成：支持最小化到系统托盘（托盘显示当前歌曲名），右键托盘可快速控制播放；
   快捷键：全局快捷键 ——空格播放 / 暂停、→下一首、←上一首、↑音量 +、↓音量 -；
   窗口控制：支持窗口大小调整（最小宽度限制）、最大化 / 还原，播放页支持无边框模式。
3. Web 端
   PWA 支持：实现离线缓存核心功能，支持 “添加到桌面”，加载时显示启动屏；
   浏览器限制：处理 Web 端自动播放限制（首次播放需用户交互触发），提示 “点击播放按钮开始播放”；
   响应式优化：在小屏设备（手机浏览器）自动隐藏侧边栏，保留核心播放控制。

1. 测试策略
   单元测试：覆盖核心业务逻辑（播放模式切换、歌词同步、搜索匹配），通过率≥95%；
   集成测试：测试模块间交互（如 “下载→播放缓存歌曲”“登录→同步收藏”），验证数据流转正确性；

   播放进度拖拽后歌词不同步问题；
