   高级感细节：
   浅色暖调饱和度≤30%，像奶茶的温润光泽，避免橙红的刺眼感；
   深色模式用深棕黑替代纯黑，搭配米黄文本，像暖光下的木质桌面，温馨高级。
   核心设计逻辑
   浅色为主：浅色模式均采用「高明度（≥85%）+ 低饱和（≤35%）」色调，营造通透感，文本与背景对比度≥6:1，清晰不费力；
   深色适配：深色模式与浅色保持「同色系深色调」，避免色调突变，背景不用纯黑（加入 5%-10% 主色倾向），卡片色与背景色阶差≤20%，过渡细腻；
   质感统一：所有色调均加入 5%-15% 灰度中和，模拟「磨砂、哑光、纸质」等真实材质质感，远离数字廉价感。
   可根据实际界面需求微调明度，核心保持「浅色通透、深色细腻」的高级感平衡。
跨平台视觉统一：
移动端：强化主色调在按钮、导航栏的存在感，卡片阴影设为 1-2dp 轻量阴影；
桌面端 / Web 端：增加卡片阴影层次（3-4dp），文本字号稍大，辅助色在交互元素（如滑块、按钮）上更突出。
自定义主题限制：
允许用户自定义主色调时，通过算法自动生成辅助色（如主色的互补色 / 邻近色），并限制饱和度范围（30%-70%），避免用户搭配出违和感。
优化后的主题更注重「克制的色彩表达」，通过低饱和基调 + 精准的点缀色增强现代感，同时兼顾不同音乐风格的情感适配和全平台的视觉舒适度。
