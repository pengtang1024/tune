   主题实现优化建议
   动态对比度适配：
   通过 ThemeData 封装色值时，使用 ColorScheme 统一管理「主色 - 背景 - 文本」关系，确保深色 / 浅色模式下文本与背景的对比度 ≥ 4.5:1（符合 WCAG 标准）。
   dart
   // 示例：潮流轻电主题的ColorScheme
   ColorScheme lightScheme = ColorScheme(
   primary: Color(0xFF6366F1),
   secondary: Color(0xFFF43F5E),
   background: Color(0xFFFAFAFA),
   onBackground: Color(0xFF1F2937), // 文本主色（与背景对比度达标）
   // ...其他色值
   );


跨平台视觉统一：
移动端：强化主色调在按钮、导航栏的存在感，卡片阴影设为 1-2dp 轻量阴影；
桌面端 / Web 端：增加卡片阴影层次（3-4dp），文本字号稍大，辅助色在交互元素（如滑块、按钮）上更突出。
自定义主题限制：
允许用户自定义主色调时，通过算法自动生成辅助色（如主色的互补色 / 邻近色），并限制饱和度范围（30%-70%），避免用户搭配出违和感。
优化后的主题更注重「克制的色彩表达」，通过低饱和基调 + 精准的点缀色增强现代感，同时兼顾不同音乐风格的情感适配和全平台的视觉舒适度。
