# Tune - 你的私人旋律收纳箱

Tune 是一款音乐播放器应用，旨在为你提供简洁直观的界面来管理和播放本地音乐库。

## 功能特点

- **本地音乐库管理**: 轻松整理本地音乐文件
- **自定义播放列表**: 按风格、心情或场景创建播放列表
- **流畅播放体验**: 享受高品质音频播放
- **音效调节**: 通过可自定义的声音设置微调音频
- **极简界面**: 专注于音乐体验的简洁设计


## 安装步骤

1. 确保你的机器上已安装 Flutter
2. 克隆此代码仓库
3. 运行 `flutter pub get` 安装依赖
4. 连接设备或启动模拟器
5. 运行 `flutter run` 启动应用程序

## 支持平台

- Android
- iOS
- Linux
- macOS
- Windows
- Web
