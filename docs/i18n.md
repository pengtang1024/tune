# 国际化

> AGENTS.md 的展开文档。改文案、切语言、加音源名称前读这份。

## 目录与模板

- ARB 在 `lib/l10n/`：模板是 `app_zh_CN.arb`，`app_en.arb`、`app_zh.arb`、`app_zh_TW.arb` 必须同步补齐。
- `l10n.yaml` 指定了 `arb-dir: lib/l10n` 与 `output-localization-file: app_localizations.dart`，所以生成产物落在 `lib/l10n/`。
- **生成产物入库**：提交 `lib/l10n/app_localizations*.dart`，不要加进 `.gitignore`。

## 新增文案的流程

1. 改 `lib/l10n/app_zh_CN.arb`（模板）。
2. 同步其它语言，键名与条数必须一致。
3. `flutter gen-l10n` 重新生成。
4. 提交 ARB 与生成的 `lib/l10n/app_localizations*.dart`。
5. `flutter test test/app/localization_test.dart` 与 `test/app/localization_render_test.dart` 必须过。

## 取文案的两种方式

| 场景 | 写法 |
| --- | --- |
| widget 树内 | `context.loc.xxx`（`lib/core/extension/localizations_extension.dart`） |
| widget 树外（controller、service） | `AppStrings.instance.xxx`（`lib/core/l10n/app_strings.dart`） |

`AppStrings` 由 `LocalizationBridge`（`lib/core/l10n/localization_bridge.dart`）跟随界面语言同步；需要指定语言的文案用 `AppStrings.of(locale)`。

## 会被测试抓住的错误

- **界面有硬编码文案**：`test/app/localization_test.dart` 扫源码。
- **界面漏出另一种语言的原文**：同一份测试扫源码，`test/app/localization_render_test.dart` 另外渲染界面读树。
- **某语言缺键 / 多键**：`test/app/localization_test.dart` 比对各 locale 的目录。
- **界面文案超出控件宽度**：`test/app/localization_render_test.dart` 检查标签长度——英文比中文长，这是中文布局最常被撑破的地方。

## 专有名词

品牌名、格式名（`Tune`、`Openverse`、`MP3`…）在所有语言里写法一致，清单在 `test/app/localization_words.dart`：

- 新增音源名要同时加进该清单。
- 品牌名音源还要给一条本地化名（chip 上的小字），规则见 `需求/多语言设计.md` 的「音源的两个名字」。

## 数字

- 按 locale 分组（`intl`），不要自己拼千位分隔符。
- 数字格式由 `test/app/localization_numbers_test.dart` 守着。
